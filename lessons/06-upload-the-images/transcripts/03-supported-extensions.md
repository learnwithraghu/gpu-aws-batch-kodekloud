# Video 03 — Supported file types
**Type:** Theory  
**Runtime target:** ~3–4 minutes

---

**What the code filters.** **`.jpg`**, **`.jpeg`**, **`.png`** (case-insensitive). Others **skipped silently** — no row, no error per file.

**Why intentional.** Catalog targets **standard menu photography**, not every HEIC/RAW variant.

**Example support ticket.** “30 photos, 28 rows” → find **`.heic`** siblings in prefix.
