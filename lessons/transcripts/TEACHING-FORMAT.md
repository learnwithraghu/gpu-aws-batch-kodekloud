# Transcript teaching format (expanded)

Each **theory** script is written so a student hears four layers, not just course-specific names:

1. **What it is** — plain definition in one sentence, then unpack the term.
2. **Why it exists** — what breaks or gets expensive without this concept.
3. **Example** — generic AWS pattern first, then this course’s names/values where relevant.
4. **Visual** — what Remotion should show while this audio plays.

**Runtime:** Expanded theory clips target **~3–4 minutes** (~450–600 words at teaching pace). Demos add **~30–60 seconds** of “what we’re about to do and why” before on-screen actions.

Demos still follow each lesson README; theory is not limited to repo inventory — include background students need (ECS, IAM, quotas, containers) to reason on their own accounts.
