# Video 04 — When to re-run what
**Type:** Theory  
**Runtime target:** ~3–4 minutes

---

**Decision matrix (teach as runbook).**

| Change | Rebuild image? | Re-upload? | Resubmit? |
|--------|----------------|------------|-----------|
| New photos, same folder | No | Yes (sync) | Yes |
| Prompt / generate / code | Yes (03–04) | No | Yes |
| FAILED after infra fix | If code changed | If data wrong | Yes |
| Read existing catalog | No | No | No |

**Why overwrite same key.** Latest successful catalog for stem — ops always know path.
